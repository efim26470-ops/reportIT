Как запустить локально

1. Скачайте репозиторий или ZIP-архив проекта.
2. Откройте файл index.html в браузере.
3. Для корректной проверки скачивания архива убедитесь, что файл айтишка.zip лежит рядом с index.html.

Как обновить архив с работами

Чтобы кнопка скачивания продолжала работать без изменения кода:

1. Замените файл айтишка.zip в корне репозитория.
2. Оставьте то же имя файла: айтишка.zip.
3. Закоммитьте изменения в ветку main.
4. GitHub Pages автоматически обновит сайт через несколько минут.

Добавление сайта на экран «Домой» на iPhone

Сайт подготовлен как web app:

1. Откройте сайт в Safari.
2. Нажмите кнопку «Поделиться».
3. Выберите «На экран Домой».
4. После добавления сайт будет отображаться с отдельной иконкой приложения.
